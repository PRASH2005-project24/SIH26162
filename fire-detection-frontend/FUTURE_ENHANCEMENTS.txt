**Why:** Thousands of requests per minute need fast responses.

- Connection pooling (PostgreSQL)

**Backend Implementation:**
- Use Redis for: event lists, statistics, predictions
- Invalidate cache when data changes
- Serve static files from CDN (CloudFront, Cloudflare)


### 10.4 SECURITY HARDENING
**Why:** Production system needs enterprise-level security.

**What to Add:**
- HTTPS only (TLS 1.3)
- JWT authentication with refresh tokens
- Role-based access control (RBAC)
- Rate limiting (100 requests/min per user)
- Input sanitization (prevent SQL injection, XSS)
- CORS configuration (whitelist allowed origins)
- API key authentication for external integrations
- Audit logging (all API requests logged)
- Password policies (min 8 chars, complexity requirements)
- Two-factor authentication (2FA) for admin users

**Backend Implementation:**
- Use JWT tokens (access token 15 min, refresh token 7 days)
- Validate all inputs with middleware
- Use parameterized queries (no raw SQL)
- CORS whitelist: only frontend domain allowed
