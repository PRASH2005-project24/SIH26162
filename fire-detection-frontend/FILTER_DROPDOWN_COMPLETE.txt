JAVASCRIPT CHANGES (script.js)
================================================================================

NEW FILTER MENU FUNCTION:
────────────────────────
function toggleFilterMenu() {
    const filterMenu = document.getElementById("filter-menu");
    if (filterMenu) {
        filterMenu.classList.toggle("show");  ← Toggles .show class
    }
}

ENHANCED initializeFilterMenu():
─────────────────────────────────
1. Get references to button, menu, options
2. Add click listener to filter button
   └─ toggles "show" class on menu
3. Add click listener to each option
   └─ Removes active class from all
   └─ Adds active class to clicked option
   └─ Removes "show" class from menu (closes it)
   └─ Logs filter selection to console
4. Add global click listener
   └─ Closes menu when clicking outside
   └─ Uses event.stopPropagation() to prevent conflicts

EVENT FLOW
================================================================================

CLICK SEQUENCE:
───────────────
User click Filter button
    ↓
toggleFilterMenu() called
    ↓
filterMenu.classList.toggle("show")
    ↓
CSS shows menu (.filter-menu.show { display: block; })
    ↓
Menu visible below button

User click option (e.g., "Today")
    ↓
Option click handler:
  - Stop propagation (prevent bubbling)
  - Get filter value ("today")
  - Log to console
  - Remove .active from all options
  - Add .active to clicked option
  - Remove .show from menu
  ↓
Menu closes, option shows red background


CLICK OUTSIDE:
──────────────
User click outside menu
    ↓
Document click handler:
  - Check if click inside filterBtn
  - Check if click inside filterMenu
  - If neither, remove .show class
  ↓
Menu closes
