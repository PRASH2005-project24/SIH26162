# Contributing to SIH26162

Thank you for contributing to our Smart India Hackathon project.

## Project Overview

SIH26162 focuses on detecting and classifying industrial fires and persistent thermal sources using satellite thermal observations, geospatial data, and machine learning.

## How to Get Started

1. Fork the repository on GitHub.
2. Clone your fork to your local computer.
3. Read the README.md file and follow the project setup instructions.
4. Install the required dependencies before running the application.
5. Create a separate branch for each contribution.

## Development Workflow

Create a feature branch before making changes:

```bash
git switch -c feature/your-feature-name
```

Make your changes and test them locally.

Check the changed files:

```bash
git status
```

Commit your work:

```bash
git add .
git commit -m "Describe your changes"
```

Push your branch:

```bash
git push -u origin feature/your-feature-name
```

## Pull Request Guidelines

When submitting a Pull Request:

- Explain the purpose of your changes.
- Describe the files or features modified.
- Include testing steps and results.
- Link any related issues.
- Keep changes focused on one task.
- Respond to review feedback before merging.

## Code Quality

- Follow the existing project structure and coding style.
- Avoid unnecessary changes to unrelated files.
- Test changes before submitting them.
- Do not commit API keys, passwords, `.env` files, or private credentials.
- Do not commit large datasets or generated files unless the project explicitly requires them.

## Reporting Bugs

When reporting a bug, include the steps to reproduce it, the expected behavior, the actual behavior, and any relevant error messages.

## Thank You

Every improvement to the documentation, data pipeline, backend, machine learning components, and frontend helps improve the project.
